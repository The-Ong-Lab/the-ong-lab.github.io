# The Ong Lab website

Static site served by GitHub Pages at https://the-ong-lab.github.io

- Pages: index.html, research.html, publications.html, team.html, collaborations.html, join.html, contact.html
- Styles: style.css
- Images: images/ (team headshots are images/team-<name>.jpg; logos are images/logos/<key>.png)

To update text, edit the HTML file for that page and commit. Changes go live a minute or two after each commit.
Do not add patient data, identifiable images, or research code to this repository.
